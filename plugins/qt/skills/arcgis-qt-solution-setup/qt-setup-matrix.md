# ArcGIS Maps SDK for Qt setup matrix

## Supported app styles

- Qt Quick / QML
- Qt Widgets

## Typical targets

- Windows
- Linux
- macOS
- Android
- iOS

## Common environment pieces

- matching Qt SDK and compiler/toolchain
- Qt Creator kits configured for the target platform
- ArcGIS Maps SDK for Qt installed and configured
- qmake or CMake integration depending on the project

## Toolkit guidance

The ArcGIS Maps SDK for Qt toolkit provides:

- Qt Quick UI components for QML-based apps
- Qt Widgets UI components for desktop-style widget apps

Prefer toolkit components when they solve the requested UI cleanly.
